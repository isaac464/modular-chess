[2026-06-03] ENGINE REFACTOR & RULE COMPLIANCE
- Refactored check validation (`wouldBeInCheck`) to pass an isolated, simulated board array through the verification chain, preventing sliding pieces from "looking through" the King's old square.
- Reordered piece execution sequence in `movePiece` to ensure En Passant captures are cleared from the grid before wiping out the move target for the subsequent turn.
- Patched structural castling loopholes by validating the `hasMoved` flags for both the King and the specific Rook, and ensuring the King cannot castle out of, through, or into check.
- Fixed an open-ended CSS animation keyframe issue in `style.css` that was preventing the King check-flash from fading out seamlessly.

[2026-06-03] QUALITY OF LIFE FEATURE: ARROWS
- Implemented dynamic SVG overlay system matching the canvas dimensions.
- Integrated right-click event interception (`oncontextmenu`, `onmousedown`, `onmouseup`) to record analysis sweeps.

[2026-06-03] UI ENHANCEMENT: L-SHAPED ARROWS
- Migrated arrow rendering from SVG Line to SVG Polyline.
- Added pathfinding logic for "Knight-style" movements to create a 90-degree elbow.

[2026-06-03] UI OVERHAUL: OUTSIDE BOARD LABELS
- Re-architected board structure to separate coordinates from square DOM elements using grid wrapping.

[2026-06-05] UI & ANIMATION ENHANCEMENTS
- Implemented a side-panel move log using standard algebraic notation to track all match activity.
- Integrated an "Undo" system; for bot matches, this reverts two plies to return to the player's previous turn.
- Refactored piece rendering to utilise CSS transitions for smooth movement and capture visualisations (fade and scale effects).
- Added a "Check Flash" animation to highlight the King's square when under threat.
- Introduced a post-game "Analysis Mode" allowing users to navigate the full game history via state snapshots.
- Overhauled responsive scaling using CSS `clamp()` and `vmin` units to ensure layout integrity across diverse viewport dimensions.
- Resolved SVG arrow misalignment issues by implementing a window-resize listener for automatic coordinate recalculation.

[2026-06-10] BOT ENGINE ENHANCEMENTS
- Upgraded "Hard" bot to use Minimax search with a fixed depth of 4 plies.
- Implemented Alpha-Beta pruning to significantly reduce the search space.
- Integrated Quiescence Search to mitigate the "horizon effect" by extending search through capture sequences.
- Added MVV-LVA (Most Valuable Victim - Least Valuable Attacker) move ordering to improve pruning efficiency.
- Integrated an algebraic-notation-based Opening Book for diverse and theoretical early-game play.
- Introduced randomized move selection among top-evaluated candidates to ensure non-deterministic behaviour.

[2026-06-12] SANDBOX MODE & CUSTOMISATION

- Created a piece palette with responsive grid layout for spawning pieces directly onto the board.
- Integrated an "Eraser" tool within the palette to remove pieces from the board.
- Added a "Free Piece Movement" toggle that bypasses all chess rules and turn validation.
- Implemented an "Empty Board" start setting for custom position initialisation.

[2026-06-14] GAME TIMERS & ACCESSIBILITY
- Implemented a dual-timer system with support for standard blitz and rapid time controls.
- Added a "low-time" visual state with a pulse-red animation when a player has less than 30 seconds remaining.
- Integrated ARIA labels and keyboard navigation (tabindex, focus-visible states) for all interactive menu cards and game controls.
- Refactored move history with a paginated UI (10 moves per page) to ensure panel performance and readability during long matches.
- Enhanced coordinate rendering to automatically remap and rotate labels based on the active board perspective.

[2026-06-15] REFINEMENT & DRAW CONDITIONS
- Implemented Stalemate detection for games with no legal moves but no active check.

- Synchronised undo logic with the game timer to ensure time is accurately restored to the start of the previous turn.
